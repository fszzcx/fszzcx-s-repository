# My Computer Science Journey

一个计算机专业大一学生的代码库：记录 C++ 学习、算法刷题与项目实践的成长轨迹。

## 目录结构

```
├── cpp-learning/          # C++ 学习
│   ├── notes/             # 学习笔记（本地，不入库）
│   ├── basic-exercises/   # 基础语法练习（VSCode/WSL）
│   └── mini-projects/     # Visual Studio 小工程
├── algorithm-practice/    # 算法刷题
│   ├── luogu/             # 洛谷题解
│   └── weekly-review/     # 每周复盘
├── python-learning/       # Python 学习（规划中）
└── projects/              # 完整项目（未来）
```

## 环境

- **Visual Studio 2026**（MSVC v145）— 主力 IDE
- **VSCode + MSYS2 (ucrt64 g++)** / **WSL** — 轻量练习与跨平台编译
- 编码约定：源码 UTF-8 with BOM，`/source-charset:utf-8`
